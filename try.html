이 페이지에서 되는 것 — 내장 프리셋 9종과 라이트룸 .xmp 적용, 강도 0~100%, 원본과 비교, 결과 PNG 저장. 방향키 ← → 로도 넘어갑니다.

여기서는 안 되는 것 — 카메라 미리보기·사진 촬영·영상 녹화입니다. 브라우저가 이 페이지에 카메라 권한을 주지 않기 때문이며, 앱이 못 하는 것이 아닙니다. 카메라까지 보려면 저장소를 받아 npm run preview 로 열거나, APK 를 설치하세요.

색은 GPU 셰이더로 라이트룸 파이프라인을 근사한 결과입니다. 렌즈 보정·노이즈 제거·마스킹· 프로파일(.dcp)은 반영되지 않습니다. 올린 사진은 이 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.
