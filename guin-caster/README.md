# 구인 캐스터

구인광고를 **한 번만 쓰면** 채널마다 다른 문안으로 바꿔주고,
게재를 순서대로 안내하고, **언제 다시 올려야 하는지 기억**하는 앱입니다.

폰 브라우저에서 바로 쓸 수 있고, 같은 코드로 안드로이드 앱으로도 빌드됩니다.

---

## 먼저 알아두실 것 — 무엇이 자동이고 무엇이 아닌가

**이 앱은 글을 대신 올려주지 않습니다.** 못 만든 게 아니라, 올릴 수 있는 통로가 없습니다.

| 채널 | 외부 프로그램이 글을 등록할 수 있나 |
|---|---|
| 네이버 블로그 | ❌ 글쓰기 API 가 2020년 5월 폐지 (광고성 대량 포스팅 때문) |
| 네이버 카페 · 지역 커뮤니티 | ❌ 등록 수단 없음 |
| 당근알바 | ❌ 등록 수단 없음 |
| 카카오톡 오픈채팅 · 단톡방 | ❌ 임의의 방으로 메시지를 보내는 API 가 열려 있지 않음 |
| 사람인 · 잡코리아 · 알바천국 · 워크넷 | ❌ 공개 API 는 **공고 조회 전용**, 등록 API 없음 |

자동 로그인·자동 클릭 매크로로 우회하는 방법은 전부 각 사이트 약관 위반이고
계정이 정지될 수 있습니다. 구인 계정 하나 막히면 손해가 훨씬 크기 때문에 넣지 않았습니다.

**대신 이 앱이 하는 일 —** 사람이 하는 일을 붙여넣기 한 번으로 줄입니다.

```
공고 한 번 작성
      ↓
채널마다 다른 문안 자동 생성   (블로그용 긴 글 / 카페용 / 당근용 / 오픈톡용 4줄)
      ↓
게재 큐 — 채널을 하나씩 띄움
      ↓
문안은 이미 클립보드에 있음 → 붙여넣기 → 등록 → "올렸어요"
      ↓
다음 채널로 자동 이동
      ↓
며칠 뒤 "다시 올릴 때가 됐습니다" 알려줌
```

채널 하나당 10초쯤 걸립니다. 5개 채널이면 1분 안에 끝납니다.

| 채널별 권장 글자수 · 초과 경고 | ✅ |
| 게재 큐 (복사 → 채널 열기 → 완료 → 다음) | ✅ |

| 채널별 끌어올리기 주기 관리 · 오늘 올릴 곳 알림 | ✅ |
| 게재 이력 기록 | ✅ |
| 문안 템플릿 직접 수정 | ✅ |
| 채널 직접 추가 · 순서 변경 · 켜고 끄기 | ✅ |
| 최저임금 미만 시급 · 연락처 누락 등 사전 점검 | ✅ |

### 처음 들어있는 채널

네이버 블로그 · 지역 맘카페 · 당근알바 · 오픈톡방 · 동네 단톡방

실제로 쓰시는 곳으로 바꾸시면 됩니다. 오픈톡방은 **방마다 하나씩** 만드시는 걸 권합니다 —
방별로 마지막 게재 시각이 따로 관리돼야 끌어올리기가 제대로 돌아갑니다.

---

## 문안 템플릿

`{{항목}}` 자리에 공고 내용이 들어갑니다. 규칙은 두 개뿐입니다.

1. `{{지역}}` → 공고의 지역 값으로 바뀝니다.
2. **값이 비어 있는 항목이 들어간 줄은 통째로 사라집니다.**

2번 덕분에 공고를 대충 채워도 `급여 : ` 같은 빈 껍데기가 남지 않습니다.

쓸 수 있는 항목:
`업체명` `직무` `지역` `근무형태` `근무시간` `급여` `자격` `복지` `상세` `연락처` `마감` `태그`

채널 종류(블로그 / 카페 / 당근알바 / 오픈톡·단톡 / 문자 / 기타)마다 템플릿이 하나씩 있고,
[채널] 탭 아래쪽에서 고칠 수 있습니다. 고치는 동안 실제 공고로 미리보기가 나옵니다.

## 폴더 구조

```
guin-caster/
├─ www/                  ← 앱 본체 (이것만 고치면 됩니다)
│  ├─ index.html
│  ├─ styles.css
│  └─ js/
│     ├─ store.js        저장소 · 데이터 모델 · 끌어올리기 계산
│     ├─ compose.js      공고 → 채널별 문안 변환 엔진
│     ├─ publish.js      클립보드 · 공유 · 채널 열기 · 게재 큐
│     ├─ card.js         공고 요약 이미지 (캔버스, 외부 라이브러리 없음)
│     ├─ ui.js           화면 전체
│     └─ app.js          부팅 · 뒤로가기
├─ scripts/
│  ├─ preview-server.js  PC 브라우저 미리보기용 정적 서버
│  ├─ make-icons.js      앱 아이콘 생성 (외부 라이브러리 없음)
│  └─ patch-android.js   앱 이름 · 세로 고정 · 카카오톡/당근 열기 권한
└─ capacitor.config.json
```

빌드 도구가 없습니다. `www/` 를 고치면 새로고침만 하면 됩니다.

## 실행

### PC 브라우저에서 보기

```bash
npm run preview      # → http://localhost:5184
```

### 폰에서 쓰기 (설치 없이)

`www/` 를 아무 정적 호스팅(GitHub Pages 등)에 올리고 폰 브라우저로 열면 됩니다.
크롬 메뉴 → "홈 화면에 추가" 하면 앱처럼 열립니다.

> 클립보드 복사는 **https 에서만** 동작합니다. http 로 열면 복사 버튼이 실패합니다.

### 안드로이드 앱으로 빌드

```bash
npm install
npm run icons
npx cap add android
npm run android:sync
npx cap open android      # 안드로이드 스튜디오에서 실행
```

`patch-android.js` 가 앱 이름, 세로 고정, 그리고 **카카오톡·당근을 띄우기 위한
`<queries>` 선언**을 넣어 줍니다. 안드로이드 11 부터는 이 선언이 없으면 다른 앱이
설치돼 있어도 "없는 것"으로 보여서 열기가 안 됩니다.

## 저장되는 곳

전부 기기 안(localStorage)에만 있습니다. 서버로 나가는 것이 없습니다.
기기를 바꾸실 때는 [설정] → 내보내기 로 만든 `.json` 을 옮기고 가져오기 하시면 됩니다.

## 앞으로 붙일 수 있는 것

지금은 안 되지만 **실제로 완전 자동화가 가능한** 채널들입니다.
필요해지면 이 순서로 붙이는 게 값어치가 큽니다.

| 채널 | 방법 | 비용 |
|---|---|---|
| 문자 (SMS · LMS) | 솔라피 · 알리고 등 문자 API | 건당 과금 |
| 이메일 | SMTP 또는 메일 API | 사실상 무료 |
| 카카오 알림톡 · 친구톡 | 카카오 비즈메시지 (내 채널 친구 대상) | 건당 과금 |
| 인스타그램 · 페이스북 페이지 | Meta Graph API (비즈니스 계정) | 무료 |
| 텔레그램 · 디스코드 · 슬랙 | 봇 API | 무료 |
| 자체 블로그 (워드프레스) | REST API | 무료 |

이 채널들은 버튼 하나로 **실제 발송까지** 됩니다.
지원자 유입이 어느 채널에서 오는지 추적하려면, 채널마다 다른 연락 링크를 붙이면 됩니다.
